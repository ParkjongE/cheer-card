과몰입 응원단 — 한 줄 치면 우주까지 응원해요

■ 실행 방법
  index.html 을 더블클릭하면 브라우저에서 바로 열려요. 설치 · 로그인 · 서버가 필요 없어요.

■ 쓰는 법
  1. 응원할 일을 한 줄 적고 과함 단계를 골라요.
  2. 「응원 링크 만들기」를 누르고 링크를 복사해 보내요.
  3. 받는 사람이 링크를 열어 봉투를 누르면 응원이 시작돼요.
  4. 응원이 끝나면 받은 사람이 「답장하기」로 한마디를 링크로 돌려보낼 수 있어요.
  5. 응원 중에 화면을 누르면 누른 자리에서 꽃가루와 구호가 터져요. 마우스를 움직이거나 기기를 기울이면 화면이 출렁여요.

■ 지킨 것
  - 쓴 글은 주소의 # 뒤에만 담겨요. 서버로 보내거나 저장하지 않아요.
  - 이름 · 연락처 · 위치를 받지 않아요.
  - 카드에 나오는 응원 인원과 속보는 전부 과장한 모의 데이터이고, 첫 화면에 밝혀 두었어요.
  - 바깥 서버 · CDN · 글꼴을 부르지 않아요. 인터넷이 없어도 돌아가요.
  - 만들어지는 링크는 같은 파일을 올려 둔 공개 주소(https://parkjonge.github.io/cheer-card/)를 가리켜요.
    받는 사람이 어디서든 열 수 있게 하려는 것이고, 글은 # 뒤에만 붙어 그 서버로도 전송되지 않아요.

■ 쓴 소재와 라이선스
  - 남의 사진 · 그림 · 음원 · 라이브러리를 쓰지 않았어요.
  - 캐릭터, 지구 · 태양계 · 은하, 목소리(옹알이), 효과음은 전부 코드로 직접 그리고 합성했어요.

■ 파일
  index.html   화면 뼈대
  style.css    모양
  app.js       응원 순서 · 캐릭터 · 소리
  space.js     지구 · 태양계 (WebGL 셰이더로 직접 그림)
